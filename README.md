# Σύστημα Διαχείρισης Αποθήκης & Ειδικού Βιβλίου Τελωνείου 🏛️📦

Μια ολοκληρωμένη Desktop εφαρμογή γραμμένη σε **Python (Tkinter)** με ενσωματωμένη βάση δεδομένων **SQLite**. Το πρόγραμμα σχεδιάστηκε για την παρακολούθηση αποθεμάτων (Πρώτων & Βοηθητικών Υλών), τη διαχείριση προμηθευτών, και την **αυτόματη δημιουργία του Ειδικού Πρόχειρου Βιβλίου Τελωνείου** (σύμφωνα με το άρθρο 2 της Π.8272/4880/ΠΟΛ364/10/12/87 Α.Υ.Ο.).

## 🌟 Βασικά Χαρακτηριστικά

- **📋 Διαχείριση Προμηθευτών:** Προσθήκη, προβολή, αναζήτηση (βάσει ΑΦΜ) και διαγραφή προμηθευτών, συμπεριλαμβανομένων στοιχείων όπως η Δ.Ο.Υ.
- **📦 Διαχείριση Προϊόντων:** Σύνδεση προϊόντων με συγκεκριμένους προμηθευτές και παρακολούθηση του συνολικού τους υπολοίπου.
- **💸 Κινήσεις Αποθήκης (Χρεώσεις / Πιστώσεις):** 
  - Καταγραφή Αρ. Πρωτοκόλλου και Αρ. Τιμολογίου.
  - **Έξυπνο Σύστημα FIFO:** Κατά την "Πίστωση" (εξαγωγή), το σύστημα εντοπίζει και μειώνει αυτόματα το υπόλοιπο από τα παλαιότερα ανοιχτά τιμολόγια ("Χρεώσεις") μέχρι να κλείσουν.
- **🏛️ Ειδικό Βιβλίο Τελωνείου:** 
  - Αυτόματη παραγωγή του επίσημου πίνακα με τον Αύξοντα Αριθμό (Α/Α), τρέχοντα υπόλοιπα, χρεωπιστώσεις και στοιχεία τιμολογίων.
  - Επιλογή ελέγχου των τρεχόντων **Ανοιχτών Τιμολογίων** ανά προϊόν.
  - **🖨️ Άμεση Εκτύπωση:** Δημιουργία δυναμικού αρχείου HTML και προεπισκόπηση για άμεση, τέλεια εκτύπωση σε χαρτί.
- **📊 Αναφορές (Εξαγωγή σε Excel):** Δυνατότητα εξαγωγής των υπολοίπων της αποθήκης και του ιστορικού των κινήσεων σε μορφή CSV (συμβατή πλήρως με το Ελληνικό Excel, `utf-8-sig`).

## 🛠️ Τεχνολογίες που χρησιμοποιήθηκαν

- **Γλώσσα Προγραμματισμού:** Python 3
- **Γραφικό Περιβάλλον (GUI):** Tkinter (ενσωματωμένη βιβλιοθήκη)
- **Βάση Δεδομένων:** SQLite3 (δημιουργείται και αναβαθμίζεται αυτόματα)
- **Εξαγωγή Αρχείων:** `csv`, `tempfile`, `webbrowser`
